# תמונות משחקים מ־Google Drive

מייבא תמונות מקור של קהל ושחקני הפועל באר שבע לגלריות המשחקים הקיימות. אין שינוי סכמה או UI.

האצווה הנוכחית כוללת **1,085 תמונות** מתוך 1,140 קבצים שנבדקו חזותית. 36 תמונות חסרות תאריך צילום ונשארות לבדיקה. בבדיקה מול העותק המקומי נמצאו 383 תמונות המתאימות ל־14 משחקים; 666 תמונות עם תאריך צילום לא מצאו משחק מקומי באותו יום. השיוך מחושב מחדש במסד היעד, שעשוי להכיל משחקים נוספים.

הקטלוג הפרטי `data/drive-photos/manifest.json` מכיל רק רשומות שנבדקו חזותית, עם מזהה קובץ מקור ב־Drive ותאריך צילום מקורי מתוך EXIF. **הקטלוג והתמונות אינם נכללים במאגר הציבורי**; הם מסופקים בחבילה פרטית. לא משתמשים בתאריך העלאה או שינוי ב־Drive. תאריך ללא offset נשמר כתאריך ושעה מקומיים של המצלמה; אין המרה שרירותית ל־UTC. צילומים אחרי חצות אינם משויכים אוטומטית למשחק של היום הקודם.

הייבוא קורא מחדש את המשחקים במסד היעד ומצרף תמונה רק כשיש משחק **יחיד** של הפועל באר שבע באותו תאריך בישראל. תאריכים חסרים או כפולים נשארים בדוח בדיקה. גם צילום ללא תאריך צילום מאומת נשאר לבדיקה. אין זיהוי שחקנים אוטומטי ואין החלפה של תמונות פרופיל.

המסד חייב להיות מסונכרן עם הסכמה הקיימת ב־`prisma/schema.prisma`, הכוללת כבר `MediaAsset.gameId`. בעותק המקומי נמצאה העמודה חסרה: בדיקת השיוכים הצליחה, ובדיקת הכתיבה בוצעה בסכמת PostgreSQL מבודדת עם rollback. נוצרו 383 שורות בדיקה, הרצה חוזרת לא יצרה כפילויות, ובסיום לא נשארו שורות. סכמה ונתונים קיימים לא שונו. ה־PR אינו מוסיף שדות או דורש שינוי סכמה נוסף מעבר לסכמה הקיימת בפרויקט.

## הכנת השרת והרצה

הקבצים הבינריים נשמרים בנפרד מ־Git, לפי קונבנציית `public/uploads/` של הפרויקט. יש להעביר את חבילת `reviewed-photos.tar.gz` המוכנה מהמחשב שבו בוצעה הבדיקה לשרת ולחלץ **מתיקיית הפרויקט**:

```bash
tar -xzf /path/to/reviewed-photos.tar.gz
node scripts/drive-photos/import.js --report /tmp/drive-photos-preview.json
# לקרוא את assignments ואת skipped בדוח לפני החלת השינויים
node scripts/drive-photos/import.js --apply --report /tmp/drive-photos-applied.json
```

החבילה מכילה את הקטלוג הפרטי ב־`data/drive-photos/manifest.json` וקובצי JPEG מתחת ל־`public/uploads/games/drive-photos/`. הקבצים הוקטנו עד 1600px, ופרטי EXIF, GPS ומזהי מצלמה הוסרו. המקור המלא נשאר פרטי ב־Drive ובתיקיית `data/drive-photos/` המקומית. אין תמונות פרטיות, מזהי קבצים ב־Drive, תאריכי צילום ממשיים או קישורי הורדה זמניים ב־Git. `discovery.json` מכיל ספירות מסכמות בלבד.

אפשר לבחור מסלול חלופי עם `--public-root /absolute/path/to/public` או קטלוג חלופי עם `--manifest /absolute/path/to/manifest.json`. משתני סביבה נטענים מקובצי הסביבה הרגילים של Next.js בשורש הפרויקט.

הרצה ללא `--apply` היא בדיקה בלבד. לפני הכתיבה מאומתים כל הנתיבים, הגדלים וחותמות SHA-256. כל הכתיבות מתבצעות בטרנזקציה אחת; מזהי מדיה המבוססים על תוכן מונעים יצירה חוזרת. תמונות חדשות מתווספות בסוף הגלריה בלי לשנות רשומות קיימות או תמונה ראשית. סתירה בין רשומה קיימת לשיוך החדש מפסיקה את הטרנזקציה.

## בדיקות

```bash
node --test scripts/drive-photos/import.test.js
```

הבדיקות מכסות יום בישראל, תאריך לא תקין, תמונות שלא אושרו, מקור תאריך לא מאומת, משחק חסר או כפול, קבוצה אחרת, צילום אחרי חצות, חשיפת השיוך בדוח, כפילות תוכן, נתיב לא תקין, קובץ שהשתנה והרצה חוזרת ללא דריסה.

## הגיבוי של האתר הישן

אותר `hbs-backup.gz` בתיקיית `hbs site` והורד דרך דפדפן מחובר, משום שגודלו חורג ממגבלת מחבר Drive. נבדקו טבלת `gallery` ותיקיית המדיה הציבורית הראשית: 241 קבצים, ובהם גרפים, צילומי טלוויזיה ותמונות עם קרדיט לצלמים אחרים. אין בטבלת הגלריה תאריך משחק או הוכחה שכל הקבצים צולמו בידי בעל האתר, ולכן הם לא מיובאים אוטומטית ולא מיוחסים אליו. הגיבוי המלא וקובצי SQL אינם חלק מה־PR.

החיפוש ב־Drive מחזיר גם תוצאות שאינן צילומי מקור. שני החיפושים המורחבים `football` ו־`soccer` הושלמו עם כל דפי התוצאות: 5,219 מועמדים ייחודיים בסך הכול. **4,079 מועמדים נוספים עדיין לא נבדקו חזותית**, ואינם נספרים כתמונות מאושרות או מוצגים באתר. האצווה הנבדקת מתועדת ב־`discovery.json`; יתר המועמדים נשארים בקטלוג המקומי הפרטי `data/drive-photos/search-complete.json`. אין כאן טענה שכל תמונות Drive כבר נבדקו או שכל תוצאת חיפוש היא תמונה שלך ממשחק הפועל באר שבע.
