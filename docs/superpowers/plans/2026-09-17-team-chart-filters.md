# תוכנית: גרפי קבוצה לפי עונה ומסגרת

1. להוסיף מודול טהור שבוחר משחקים שהסתיימו, מחלק נתוני שערים, ומחשב מיקום ליגה מצטבר; לכסות אותו בבדיקות יחידה.
2. לעדכן את דף הגרפים כך שיקרא פרמטרים `season`, `competition` ו-`compare`, יטען את הקבוצה המקבילה בעונה ואת משחקי הליגה המלאים הנחוצים למיקום.
3. להוסיף ממשק RTL למסננים ולהשוואת עד שלוש קבוצות.
4. להחליף את גרף הנקודות בגרף מיקום דינמי; להציג מצב ריק מחוץ למסגרת ליגה.
5. להריץ בדיקות TypeScript ו-Jest, לבדוק build, להעלות גרסה ולפרוס.
