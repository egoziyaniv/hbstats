# StatsAI — תוצאות תיקוני סקירת הקוד והאבטחה

תאריך: 13.09.2026. ענף: `codex/project-security-review`. גרסה: `0.37.7`.

## מצב הממצאים

כל 12 ממצאי הקוד והאבטחה בדוח המקורי טופלו בקוד ובבדיקות:

- Next.js שודרג מ־14.2.35 ל־15.5.25 וה־Anthropic SDK שודרג ל־0.125.0. ממשקי `params`, `searchParams` ו־cookies הותאמו ל־Next 15.
- אסימוני access במובייל קשורים ל־Session שמור, ולכן logout, logout-all ואיפוס סיסמה מבטלים אותם מיד.
- רוטציית refresh מתבצעת בטרנזקציה Serializable עם נעילת משתמש, זיהוי reuse וחלון retry עקבי של 30 שניות.
- אפליקציית המובייל שומרת אישורי גישה רק ב־SecureStore ומוחקת עותקים ישנים מ־AsyncStorage. משתמשים שנשענו רק על האחסון הישן יצטרכו להתחבר מחדש.
- הרשמת האדמין הראשון מוגנת מפני מרוץ מקבילי.
- rollback של merge שומר ומסיר רק אירועים והרכבים שיצרה הפעולה, ושומר שינויים מאוחרים של מנהל.
- שינוי, ביטול, מחיקה או העברה של משחק מחשבים מחדש את הטבלאות הרלוונטיות תוך שמירה על הגנת ייבוא חלקי.
- גרף דקות שערים משתמש קודם ב־teamId, מטפל בשער עצמי ומדלג על אירוע legacy שלא ניתן לזהות בבטחה.
- מסלול AI מגביל גוף, מספר הודעות, אורך הודעות, גודל הקשר ומכסה יומית למשתמש ולמערכת.
- משימות cron טוענות `.env` עם parser תקני, מגבילות שמות endpoints, נכשלות על HTTP שגוי ומוגבלות ל־30 שניות.
- CI כולל כעת production build. מגבלת Server Actions ירדה מ־500MB ל־1MB.

## סריקת תלויות לאחר התיקון

הסריקה ירדה מ־25 חבילות מסומנות, כולל critical אחת, ל־7: ללא critical וללא low, עם moderate אחת ושש high. לא הופעל `npm audit fix --force` משום שההצעות האוטומטיות הן שינויי major או downgrade שוברים:

- `next@15.5.25` מסומן moderate בגלל `postcss@8.4.31` הפנימי. npm מציע Next 16.3.5. זהו שדרוג major נפרד שדורש מסלול מעבר ובדיקות תאימות, ולכן אינו חלק מתיקון האבטחה הנוכחי.
- שש החבילות הנותרות נמצאות בשרשרת Puppeteer: `puppeteer-core`, `puppeteer-real-browser`, `rebrowser-puppeteer-core`, `@puppeteer/browsers` ו־`extract-zip`. הגרסאות הישירות כבר עדכניות בטווחי ה־major הנוכחיים; npm מציע downgrade לגרסאות ישנות. המסלול המדווח נמצא בכלי scraping מקומיים/תפעוליים ואינו מקבל ארכיון ZIP ממשתמש באתר.

יש לעקוב אחר גרסה מתוקנת של שרשרת Puppeteer ולתכנן מעבר ל־Next 16 בנפרד. הסריקה אינה הוכחה שהחולשות ניתנות לניצול בפריסה הנוכחית.

## מסירה ופריסה

השינויים קיימים מקומית בלבד בענף המבוקש. לא בוצעו push, merge או פריסה ל־Hetzner, ולא שונו נתוני הייצור. אין שינוי ב־Prisma schema, ולכן בפריסה זו אין צורך ב־`prisma db push`; עדיין יש להריץ `npm install`, `npm run build` ו־`pm2 restart hbstats` לפי נוהל הפרויקט לאחר push.

לא בוצעו smoke test מול האתר החי, סימולטור iOS או מכשיר פיזי. הבדיקות המקומיות מכסות את קוד השרת, חוזי API המובייל, האחסון המאובטח, build והפעלת production מקומית, אך אינן מחליפות בדיקת staging/production ותצוגה במכשיר.
